A clean, deterministic paper-trading bot for a 6-hour pump.fun forward replay. It watches new launches, waits for genuine early demand to show up, and only then takes a small, fixed 0.1 SOL paper position — no chasing, no oversized bets, no noise trades.

Every decision is rule-based and replayable: the same market data always produces the same trades. Entries are selective by design, favouring quality over quantity so the Sharpe ratio comes from discipline — tight sizing, clear exits, and skipping weak setups — rather than from taking many shots.
